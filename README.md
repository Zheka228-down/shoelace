## О проекте

Учебный проект по дисциплине «Использование CSS-фреймворков». Тематический сайт, посвящённый поисковой оптимизации (SEO).

**Студент:** [Писарев Евгений Александрович]  
**Группа:** [835]

## Технологии

- HTML5 — семантическая разметка
- CSS3 — кастомные стили, Grid, Flexbox, адаптивность
- CSS-фреймворк: **Shoelace** (https://shoelace.style/)
- JavaScript — бургер-меню, обработка форм
- Git + GitHub Pages

## Структура сайта

- `index.html` — Главная
- `basics.html` — Основы SEO
- `on-page.html` — Внутренняя оптимизация
- `off-page.html` — Внешняя оптимизация
- `technical.html` — Техническое SEO (таблица)
- `tools.html` — Инструменты SEO (видео)
- `checklist.html` — Чек-лист (списки)
- `blog.html` — Блог
- `contacts.html` — Контакты
